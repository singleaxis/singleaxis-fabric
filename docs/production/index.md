# Go to production

A production deployment records the same fields as the laptop path; what
changes is that the record is **authenticated, protected, durable and
encrypted**: TLS and a token on every hop, a capture policy you write, an
encrypted spool, a durable queue, and sensors bound to their own ingress.
Production needs no code change.

On a single host the whole path is checked: `fabric init --production`
writes the capture policy into your project and generates every key, token
and certificate, `fabric up` starts the production Node, the destination and
the sensor, and `fabric verify --production` checks each step, every problem
with its fix: [production on a Linux host](linux-host.md). On a Node you set
up by hand, `make -C deploy/compose preflight-prod` makes the same checks with
the same ids.

| Step | Single Linux host | Kubernetes | Checked by |
|---|---|---|---|
| 1. Choose where records go | `fabric init --production --destination PRESET` ([destinations](destinations.md)) | [destinations](destinations.md) | `FC-180`, `FC-176`, `FC-188`; `FC-172` and `FC-173` say what a preset does not keep |
| 2. Keys, tokens and certificates | generated by `fabric init --production` ([secrets](secrets-and-rotation.md)) | generated in the cluster | `FC-181` to `FC-184`, `FC-187`, `FC-189`; expiry `FC-190`, `FC-191` |
| 3. The capture policy | written into your project by `fabric init --production` ([privacy and security](../reference/privacy-and-security.md)) | the chart's `injector.capturePolicy` | `FC-166`, `FC-167`, `FC-168`; the SDK refuses production without one (`FW-008`) |
| 4. Start the Node, the destination and the sensor | `fabric up` ([Linux host](linux-host.md)) | [Kubernetes](kubernetes.md) | `FC-185`, `FC-186`, `FC-192`, `FC-193`, `FC-194`; `fabric verify --kubernetes` |
| 5. Size the queue and spool | `node.queue_size` ([sizing](sizing.md)) | [sizing](sizing.md) | `FC-170`, `FC-171` |
| 6. Read a run back | `fabric verify --production` | `fabric verify --kubernetes` | the reader's verdict (`FC-065`, `FC-069`) |
| 7. Upgrade | [upgrade](upgrade.md) | [upgrade](upgrade.md) | |

On Kubernetes the whole path is checked today:
[Get started with Kubernetes](../get-started/kubernetes.md) installs the
production profile with the host sensor and verifies a run.
