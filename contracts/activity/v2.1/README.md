# Activity Envelope 2.1.0 (spec 057 §5.7)

Activity 2.1.0 is an additive contract beside 2.0.0 (`../v2`), which stays
valid and published. Contract schemas are immutable, so 2.1.0 is a new schema
and manifest rather than an edit of 2.0.0:

- the sequence `version` and the event `schema_version` accept `2.0.0` and
  `2.1.0`, so every 2.0.0 document is valid under 2.1.0;
- `event_type` gains `grant.snapshot`, `control.decision`, `hook.completed`
  and `extension.loaded`;
- `activity` gains the objects `grant`, `control`, `hook` and `extension`,
  each required by exactly its event type and forbidden on every other.

A consumer that validates strictly against 2.0.0 rejects 2.1.0 events, so a
producer emits the four new event types only when the destination declares
2.1.0. The control object is record-only: Fabric records a decision another
system made (`enforced_by_fabric` is always `false`, `authentication` always
`unverified_caller_report`) and never makes, applies, waits for or returns
one. Wire attributes map to envelope paths in `../v2/MAPPING.md`.

This contract is generated by `scripts/contracts/generate_p0_contracts.py`
(`scripts/contracts/security_context.py`) and validated by
`scripts/contracts/validate_data_plane_contracts.py`. It is not yet in the
release policy's published versions; it is published when the export path
first emits it.
